# VOID SHIFT V20：LAN／VPN 联机使用说明

房主需要在电脑上运行本地服务，队友只需浏览器。适用于同一局域网，或已能互相访问虚拟 IP 的 Radmin VPN、ZeroTier、Tailscale 等网络。普通上网 VPN 本身不会自动建立玩家之间的局域网。

## 房主启动

在项目文件夹打开终端，首次缺少依赖时执行：

```powershell
pnpm install --frozen-lockfile
```

需要 Node.js 22.13 或以上。随后查看可用地址：

```powershell
node scripts/start-lan.mjs --list
```

不带参数启动，会要求你从列表中选择网卡：

```powershell
node scripts/start-lan.mjs
```

也可以指定列表中显示的 IP，例如：

```powershell
node scripts/start-lan.mjs --ip 192.168.1.5
```

使用 VPN 时，选择 VPN 网卡的地址，不是普通 Wi-Fi 地址。默认端口为 8787；如已被其他程序占用，可加 `--port 8790`。启动器会准备过期的构建与本地数据库，然后打开房主页面。LAN 数据独立保存在 `.wrangler/lan/state`，不会重置旧开发数据库。

浏览器地址中的一次性房主凭据会自动移除。**只分享终端打印的队友网址，不分享带 `#lan-host=` 的私人房主网址。** 在房主页面选择 LAN／VPN，创建大厅。

PowerShell 入口 `scripts/start-lan.ps1` 也可使用；若系统不允许运行脚本，直接使用上面的 Node 命令，无需更改系统执行策略。

## 队友加入

打开房主分享的完整网址，例如：

```text
http://192.168.1.5:8787/game/index.html?mode=lan
```

在 V20 的任务／小队页面，也可选择 LAN／VPN，输入 `房主IP:端口` 打开对应入口。队友不需要启动服务，也不需要输入线上房间码。每个服务最多房主加三名队友；所有人都应使用同一套 V20 页面。

连上后沿用现有装备同步、准备、房主开始任务、延迟显示和踢人操作。玩法和奖励仍由房主确认。LAN 传输不使用游戏的 STUN／TURN。

## 搬入现有资产

线上 Site 与 LAN 地址拥有独立浏览器存档。先在原地址的安全屋中退出房间、等待奖励完成，再打开设置中的“个人档案”导出 JSON；到 LAN 地址导入。

导入会替换目的地的钱、装备、背包、仓库和个人记录，不合并两边资产。导入／恢复前关闭使用同一个目的地地址的其他游戏标签页。系统先保存备份，成功后刷新；“恢复备份”可撤回替换。房间令牌和待结算凭据不在导出文件内。

IP、端口或 HTTP／HTTPS 改变，也会切换到另一个存档地址。建议每次使用相同的房主 VPN 地址和端口。

## 断线与常见问题

- 队友连接中断后，有五分钟的重连窗口。房主正在运行的页面不要刷新：世界状态没有保存到服务进程，刷新或关闭可能结束本局。
- 大厅刷新可恢复房主身份；关闭本地服务会终止连接，重新启动需要重建大厅。
- 队友打不开分享的网址时，先检查 VPN 是否在同一网络、地址与端口是否正确、房主服务是否仍在运行，以及系统防火墙是否允许当前网络访问该程序／端口。
- 启动器只监听选定网卡，不会修改防火墙、路由器或端口转发，也不会修改线上数据库。
- 完成的奖励回执保存在房主的本地数据库中；服务再次启动后可继续查询未领取回执。房主未产生或上报的战绩不能凭空恢复。

结束联机时，在服务终端按 `Ctrl+C`。当前交付为本地实现，真实跨电脑 VPN 的延迟和防火墙连通性仍需你们实际验收。

## 两台电脑首次验收

先用两人小队确认以下流程，再增加到三人／四人：

1. 两人加入同一个 Radmin VPN、ZeroTier 或 Tailscale 网络。房主选对应的虚拟网卡启动，分享 **Guest URL**；队友打开这个网址，不使用线上 Site 的房间码。两端应显示 LAN 服务已就绪。
2. 房主创建房间、队友加入。确认队友分配到独立席位，装备同步结束，可准备；双方地图一致，队友延迟不是一直显示“—”。
3. 开始一局测试任务。房主把氧气瓶存入箱子，队友取走并按 C：两秒使用完成后只消耗一瓶，氧气增加50且不超过100；再次使用下一瓶不能卡在等待状态。两人争取同一件箱内物资时，也应只有一个人获得。
4. 验证一人倒地后任务仍继续，另一人靠近按一次 E 能救起；移动会取消进度。倒地者恢复40生命／30氧气。全部在线参战玩家倒地才失败。
5. 在队友端制造短暂断网后恢复，保持房主页面不刷新，确认能重连且背包、箱子和任务状态一致。先在可丢失测试物资的任务里做此项。
6. 完成成功／失败结算，核对每人的个人奖励。重新打开页面或查询同一回执不能再入账一次。大厅中另测踢人和重新加入，不要把正在进行的真实任务当作测试数据。

这些步骤涉及真实玩法与物资损失，请只携带可接受损失的测试补给。若某一步失败，记录双方浏览器、VPN类型、LAN状态和错误文字；不要公开私人房主网址、成员令牌或存档凭据。
