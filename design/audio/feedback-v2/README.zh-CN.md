# VOID SHIFT Combat & Reward Feedback V2：关键试听候选

## 当前阶段

本包完成的是计划第 1 步「素材评审」，不是完整游戏接入。共 **81 个独立音效变体、10 段正式试听、1 段离线 SMG 压力检查**。音色仍等待用户试听确认。

全部本地程序化原创，没有下载音乐或音效，没有使用录音素材或付费生成服务。V1 文件、现有游戏代码和未提交工作均保留。游戏尚未接入这些 MP3，协议仍为 V15；画面反馈、运行时 Voice Limit、动态混音和结束状态机尚未实施。

建议先低音量播放总览，再听四枪、Heavy 和胜利。音效没有经过人耳验收，数值检测不能证明真实感或“爽感”已经达标。

## 四枪区别

- **SMG：0.145 秒／发。**短爆响和枪机感，快速收尾；试听按 0.10 秒间隔连发。
- **Pistol：0.32 秒／发。**中高频瞬态、较短压力体和清楚枪机，整体干脆。
- **Revolver：0.48 秒／发。**更低、更有持续感的短压力体，以及区别于手枪的机械锁合。
- **Shotgun：0.56 秒／发。**最宽的短冲击体、强瞬态及厚实低频肩部，但没有手榴弹式长爆炸尾音。一次扳机一份音效。

四枪用相同母版峰值目标制作；解码检查确认单发峰值差小于 1.5dB，30–220Hz 能量占比按 SMG < Pistol < Revolver < Shotgun 排列。这只是声学结构证据，不能代替人耳辨识验收。

## 动态层级试听说明

总览、死亡、终端和胜利组合中加入了低音量、本地生成的参考环境底噪。重要事件附近只短暂压低该底噪，Duck 最强值覆盖而非叠乘；胜利 0.8 秒开始隔绝危险底噪。

这些是**离线混音示范**。没有在游戏中新增 Ducking、改变怪物逻辑、增加无敌、冻结普通战斗或改动任何奖励。正式接入后仍需验证真实场景下的混音、UI与动画同步。

## 技术检查与复现

- `manifest.json`：81 个单次文件、变体种子、母版哈希、分类、用途、留用决定和10段完整试听事件表。
- `qa.json`：正式 MP3 的实际解码时长、峰值、RMS、大小，以及离线四人 SMG 混音检查。
- `checks/qa-smg-four-shooters.mp3`：4 名射手、80 次开火的离线参考混音；不是多人联机验收。
- 单次及试听格式均为 48kHz、单声道、192kbps MP3。原始 WAV 保留于 `.sites-runtime/feedback-v2/masters/`，不放入游戏发布资源。
- 作者脚本为 `scripts/create-feedback-audio-v2.py`，仅使用已有本地 NumPy、FFmpeg 和 V1 数学声层函数。未安装依赖。
- 定向验收脚本为 `tests/feedback-audio-v2.test.py`，覆盖实际MP3解码、峰值、边界、时长、变体、关键时序、四枪结构和 SMG 素材重叠。
- 不运行完整测试套件，不提交、推送或发布 Site。
