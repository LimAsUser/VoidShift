# VOID SHIFT 原创音效试听 V1

这是第一阶段的音色候选，不是已接入游戏的最终音效。全部声音由本地数学合成、噪声塑形、金属共振和声层叠加制作，没有下载音乐、音效或使用外部录音，也没有调用付费生成服务。

本包包含 **46 个独立 MP3 变体、6 段试听组合**。音色是否真实、是否符合游戏，由用户试听决定；自动检测只能确认解码、时间、峰值等技术条件。

## 制作与验证记录

- 游戏候选格式：48 kHz、单声道、192 kbps MP3。单声道方便后续按位置做左右声像。
- 各单次文件有短首尾包络；MP3 解码后检查峰值和明显起始空白。没有把数值检测称为“真人听感通过”。
- `manifest.json` 保存每个素材的中文用途、原始时长、随机种子、母版哈希及试听时间轴。
- `qa.json` 保存每个 MP3 的实际解码时长、峰值、RMS、起始时间和文件大小。
- WAV 母版在 `.sites-runtime/audio-original-v1/masters/`，不属于游戏发布资源。
- 生成脚本：`scripts/create-original-audio-v1.py`；使用已有本地 NumPy 和 FFmpeg，无新安装依赖。
- 重新生成需明确传入 `--overwrite`；只复查编码文件可使用 `--verify-only`。
- 定向验收：`tests/original-audio.test.py`。没有运行项目完整套件、构建或浏览器联机测试。
