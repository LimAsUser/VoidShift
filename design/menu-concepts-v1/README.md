## Layout contract

- 标题、舱桥展示仅放在开始画面；开始游戏进入准备页，设置复用现有设置入口。
- 准备页使用一条紧凑导航与一条紧凑出发栏；不再叠加大品牌栏、资金栏和重复页标题。
- 余额常驻顶部；合约和详细风险放在简报；底部只保留难度、简短损失提醒、设施和下潜操作。
- 仓库为左 10×10 / 中央八个操作 / 右 8×5 背包；选中详情位于背包下方。待入库为空时折叠，有物资时在仓库侧展开独立列表，不把中间按钮推走。
- 仓库动作保留转移两个方向、全部存入、整理仓库、两边出售选中及两边全部出售；无可用选择时按钮禁用。
- 示例当前仓库含四件物资，合计十格；背包两瓶氧气，占四格。插画占格用于说明，不作为新物品格式或掉落数据。
- 大厅图为房主已入房、三人在线、两人准备；队友未准备时开局禁用。未入房状态保留创建/加入入口；Guest 的相同固定操作区显示准备、待确认、取消准备及离开。
- 所有准备图的按钮、余额、武器拥有状态是设计示例，不读取或改写本地存档。
- 教程插画仅作为课程预览，不代表改变游戏的俯视视角；课程序号是展示分组，不新增自动跳关功能。
- 武器与物資使用 imagegen 生成的位图展示；图中插画不是已经集成的生产资产。

## Responsive implementation rules

- Desktop 1920×1080: 顶栏约 72–86px，出发栏约 64–86px，外侧间距 12–20px；主要空间留给当前任务内容。
- Desktop 1280×720: 顶栏约 56px，出发栏约 56px，外侧间距 12px。文字重新排版，不能将 1920 设计整体缩小；正文 14–16px、辅助文字至少 12px、按钮至少 44px。
- Warehouse at 1280: 网格单格约 40px（10×10 约 400px、8×5 约 320×200px），中央区约 184px；八个 44px 动作含间隔可放在约 440px 的操作区域。网格数据区域可内部滚动，但操作区不随之消失。
- Narrow viewports: 单列/上下仓库布局，操作区在当前库存附近保持可达；七个 tab 可横向滚动。页内允许纵向滚动，底部出发栏与大厅关键操作固定在各自可见区域。
- Browser zoom: 按减少后的 CSS 可用宽高进入相应布局，不用整体 CSS scale 压小字。短屏允许当前内容区滚动。
- 保留鼠标、触摸与键盘焦点状态；hover 用青蓝微光，选中/主操作酸绿，禁用去除发光与位移。减少动态效果设置应生效。
- 所有图片是平面状态展示，不证明按钮、滚动、拖拽、联机或响应式实现已经通过测试。

## Inspection and limitations

已逐张检查生成图的整体构图、主要操作是否可见、tab 选中、关键武器价格/参数、氧气瓶数据，以及仓库列行与大厅状态文案。仓库通过追加行列标记修正了初稿格数；大厅移除了模型擅自添加的名字、等级与徽章。

原图实际尺寸：仓库 1672×940，其余 1672×941；接近 16:9，但不是原生 1920×1080。预览页提供准确 16:9 画布，保留原图、不拉伸和裁切。微小字距、格线、图中示例占格及文字排版仍属于设计示意，最终实现应由 HTML/CSS 和实际物资数据确定。

1280 布局已进行尺寸预算；没有运行真实游戏浏览器、缩放、手机端或交互测试。没有运行测试套件、build、发布、提交或推送。
