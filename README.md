# VOID SHIFT

一个零依赖的网页生存回收 Demo，灵感来自“高压合作回收”类玩法，但使用独立的世界观与视觉设计。

## 运行

直接打开 `index.html`。

## 操作

- `WASD`：移动
- `鼠标`：控制角色朝向和手电筒
- `鼠标左键 (M1)`：开火射击
- `R`：换弹
- `E`：拾取附近废料 / 沿朝向开关防爆门 / 接入安全重写终端
- `X`：呼叫撤离舱（需先破解全舰 3 处安全控制台）
- `F`：开关手电筒
- `B`：打开/关闭背包界面
- `Shift`：奔跑（消耗体力并大幅增加噪音）
- `ESC`：中断放弃当前终端 QTE 输入

## 特色

- **三联 QTE 安全终端与撤离解锁机制**：全舰随机分布 3 处紧急重写控制台，靠近按 `E` 触发 5 步随机 `WASD` 序列输入。按错将爆发**刺耳警报巨响**（瞬间吸引怪物扑袭并提高噪音至满值）；全部 3 处控制台成功重写后方可解锁紧急逃生舱（Evac Pod）。
- **完全随机程序化设施**：
  - 起始气闸舱与逃生舱在全站 12 格中完全随机分布（保证足够曼哈顿探索间距）。
  - 房间打破单纯矩形限制，拥有 L 型舱室、长条双走廊舱、切角多边形/防爆舱等非对称结构，并配有内部连通门。
  - 隔断防爆门不再死板居中，随机偏心分布且严丝合缝闭合，彻底阻断视线与手电光。
- **雷达小地图战争迷雾（Fog of War）**：初始小地图仅探明起始气闸舱，未涉足区域处于全黑未知状态；唯有玩家肉身进入新舱室后，雷达才即时点亮并揭晓房间轮廓、门位置、终端和物资。
- **怪物防同舱瞬移智能**：怪物激活、被警报惊动或攻击玩家后潜伏脱战瞬移时，绝对不会出现在玩家所在的当前房间内。
- **立体声定向空间音频**：怪物咆哮、突击爆冲与近身心跳震颤均具备真实的左右声道方位感（Directional Stereo Panning）与距离衰减。
