# VOID SHIFT

一个零依赖的科幻生存回收网页游戏，灵感来自“高压合作回收”与异形空间站探索类玩法，使用独立的世界观、纯原生 JavaScript/Canvas 与程序化生成算法构建。

---

## 🚀 如何运行游戏 (How to Run)

本项目基于纯前端 Web 技术（HTML5 + Canvas + Web Audio API），**无需安装任何复杂的后端环境或依赖包**。为确保音频与本地资源正常加载并获得最佳浏览器体验，推荐通过本地 HTTP 服务器运行：

### 方式一：使用 Python 内置服务器（推荐，最简便）
如果你的电脑已安装 Python（Windows / macOS / Linux 均通用）：
```bash
# 1. 命令行进入项目根目录
cd VoidShift

# 2. 启动本地 HTTP 服务器
python -m http.server 8000
# 若系统使用的是 python3 命令：
python3 -m http.server 8000
```
启动成功后，在浏览器（推荐 Chrome、Edge 或 Firefox）中访问：
👉 **`http://localhost:8000`**

---

### 方式二：使用 Node.js / npx
如果你的电脑已安装 Node.js：
```bash
# 进入项目根目录并使用 npx 快速启动
npx serve .
# 或者
npx http-server -p 8000
```
根据终端输出的本地地址（如 `http://localhost:3000` 或 `http://localhost:8000`）在浏览器中打开即可。

---

### 方式三：使用 VS Code "Live Server" 插件
1. 在 VS Code 中打开 `VoidShift` 文件夹。
2. 在扩展商店安装 **Live Server**（作者：Ritwick Dey）。
3. 在文件列表中右键点击 `index.html`，选择 **"Open with Live Server"**（快捷键 `Alt+L Alt+O`）。

---

### 方式四：直接双击打开（零依赖模式）
直接在系统的文件管理器中双击 `index.html`，使用现代浏览器打开。
> **提示**：根据现代浏览器安全策略，页面加载后需在界面内任意点击一次（或点击左侧“开始下潜”按钮）以唤醒 Web Audio 声音引擎。

## 🎮 操作指南 (Controls)

| 按键 / 操作 | 功能描述 |
| :--- | :--- |
| **`W / A / S / D`** | 移动角色 |
| **`鼠标移动`** | 控制角色朝向与手电筒投射光束 |
| **`鼠标左键 (M1)`** | 开火射击（支持腰射与后坐力回弹） |
| **`鼠标右键 (M2)`** | 举枪瞄准锁定（降低弹道散布并大幅减弱激光瞄准抖动） |
| **`R`** | 武器换弹 |
| **`E`** | 场景交互：拾取附近废料 / 沿朝向开关防爆门 / 接入安全重写终端 |
| **`M`** | 打开 / 关闭全局战术大地图（Tactical Facility Map） |
| **`F`** | 开关手电筒光束 |
| **`B`** | 打开 / 关闭战术背包网格界面 |
| **`Shift`** | 疾跑冲刺（消耗体力，脚步声与噪音大幅提高） |
| **`X`** | 呼叫撤离舱（需先破解全舰全部安全控制台） |
| **`ESC`** | 关闭全景大地图 / 中断放弃当前终端 QTE 输入 |

## ✨ 核心游戏机制与特色

- **设施规模自定义 (12 / 18 / 24 舱)**：下潜前可自由挑选任务规模：
  - **小型设施 (12 舱)**：配额 ¥420，3 处安全控制台。
  - **中型设施 (18 舱)**：配额 ¥680，4 处安全控制台。
  - **大型设施 (24 舱)**：配额 ¥960，5 处安全控制台。
- **有机多边形舱室与偏心门网络**：
  - 打破传统呆板方块网格，算法生成 L 型长廊、切角舱、长条双门舱等不规则结构。
  - 气闸起始舱（科技蓝）与撤离舱（警报红）在全舰对角极远端分布。
  - 防爆门非居中偏移布置，关门彻底切断视线与手电光。
- **三联 QTE 终端与防篡改过载电击**：
  - 终端紧贴边缘墙体与独立立柱布置，杜绝悬空。
  - 靠近按 `E` 接入 5 位 WASD 快速输入序列，具备 **10.0 秒倒计时限制**。
  - **15 秒怪物瞬移冷却**：按错时惊动怪物传送至隔壁邻近舱室（绝不刷在脸上），但触发 15 秒冷却，避免频繁按错导致怪物瞬移抖动。
  - **高压电击与休克硬直**：**10 秒超时** 或 **连续按错 3 次** 将触发防篡改高压电击：**扣除 10 点生命值（-10 HP）** 并使玩家陷入 **2.5 秒休克硬直**（全身电弧环绕，禁止移动、射击与交互），同时退出终端。
- **怪物 3 枪连击 10 秒休眠硬直**：
  - 在 10 秒窗口内击中怪物 3 枪，可使怪物进入 **10 秒瘫痪休眠**，期间怪物停止追击伤害，头顶显示电磁脉冲光环与倒计时。若 10 秒内未命中 3 枪，受击计数自动重置。
- **双模态战争迷雾雷达**：
  - **左上角 4×4 局部雷达**：以精致紧凑的单色战术点线呈现，仅显示探明舱室与紧邻门禁；撤离舱在踏入前保持绝密隐匿。
  - **M 键全局战术地图**：随时调阅空间站全貌、探索百分比进度与终端破解情况，支持随时切换迷雾辅助。
- **物理视线遮挡与立体声空间音频**：
  - 玩家周围的光环与手电光柱被墙体和闭合防爆门精确阴影遮挡。
  - 怪物嘶吼、脚步声、突击爆冲与微弱呼吸具备真实的方向角立体声声相（Stereo Panning）与距离衰减。
